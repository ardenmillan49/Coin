# Solana Launch Bot

محاكاة إطلاق Pump.fun بمحفظة افتراضية واحدة. بيقرأ احتياطات المنحنى من شبكة Solana وبيسجّل الشراء محلياً. البيع بأمرك. ما بيحتاج مفتاح محفظة.

## التشغيل

Python 3.10 أو أحدث. من مجلد المشروع:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python bot.py watch MINT_ADDRESS --budget-sol 0.1
python bot.py status
python bot.py sell
```

بدّل MINT_ADDRESS بعنوان العملة الرسمي. مبلغ 0.1 SOL مثال تجريبي. إذا العملة موجودة، المحاكاة بتدخل عند أول قراءة مؤكدة. إذا لسا ما ظهرت، الأمر بيضل شغّال وبيفحص كل ثانيتين. بعد الدخول فيك تسكّر البرنامج وترجع تبيع من نفس المجلد. لتخصيص مزوّد القراءة عيّن SOLANA_RPC_URL.

## فحص الإطلاق

```sh
python bot.py inspect MINT_ADDRESS
python bot.py watch MINT_ADDRESS --budget-sol 0.1 --max-creator-pct 6 --max-account-pct 10
```

قبل كل دخول، بيطبع سعر المنحنى، الاحتياطي الفعلي، حصة عنوان المنشئ، وحصة أكبر حساب من أعلى ٢٠ حساب بعد استبعاد حسابات المنحنى. الأرقام مأخوذة من قراءات مؤكدة متقاربة، وممكن تتغير بينها. حصة المنشئ بتجمع حسابات التوكن التابعة لعنوانه. ممكن الشخص يملك عناوين تانية. الحدود بالمثال اختيارية. إذا تجاوزت القراءة حدّك أو كانت حصة المنشئ مجهولة وحدّها مفعّل، بيتوقف الأمر قبل الدخول.

## الحساب والحدود

الأرقام بالتقرير بوحدات العملة الخام وlamports (كل SOL بيساوي مليار lamports). ميزانية الدخول بتحجز رسوم شبكية تقديرية للعملية والبيع. خيارات --fee-bps و --tx-fee-sol بتبدّل افتراض رسم التداول بكل اتجاه والرسم الشبكي لكل عملية. الأسعار تقديرية من الاحتياطات وبيدخل فيها أثر حجم الطلب. المحاكاة ما بتحسب إيجار حسابات أو ترتيب المعاملات. ما بتقرأ رسوم البروتوكول الفعلية.

بتدعم منحنى SOL النشط فقط. بعد الترحيل بيتوقف التسعير وبتضل الصفقة محفوظة. دعم PumpSwap/Raydium، وتنفيذ الصفقات الحقيقية لسا مراحل لاحقة. النسخة الحالية ما بتستخدم نسبة 5% أو ماركت كاب معلن لاتخاذ قرار.
